# GN Solutions Website

A responsive, dark-themed company landing page built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages.

## Files
- `index.html` — page content, service pricing packages in PKR, and sections
- `styles.css` — layout, responsive styling, animations
- `script.js` — mobile navigation, saved dark/light theme, scroll reveals, active navigation, current year, and WhatsApp inquiry form

## Preview locally
Open `index.html` in a browser. An internet connection is required for Google Fonts and Lucide icons.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `gn-solutions-website`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root (not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/gn-solutions-website/`.

For a personal site repository named `YOUR-USERNAME.github.io`, the URL will be `https://YOUR-USERNAME.github.io/`.

## Before publishing
- Update the description, services, and company details to match your business.
- The project enquiry form opens WhatsApp with a prefilled message; visitors must press **Send** in WhatsApp. The website does not store submissions.
- The globe language selector translates the page into Chinese, Urdu, Japanese, Korean, Indonesian, French, German, or Spanish using Google Translate. Automated translations may not be exact, and an internet connection is required. Pricing can be displayed in PKR, USD, EUR, GBP, CNY, JPY, KRW, or IDR using indicative rates from open.er-api.com; converted figures are estimates and final quotes are confirmed in PKR. An internet connection is needed for live rates.
- The footer LinkedIn icon links to Shehroz Chohan's profile.
- After choosing a public domain, add its canonical URL and Open Graph URL to `index.html`. Add an absolute Open Graph image URL when you have a preview image ready.
- Google Fonts and Lucide icons are loaded from external CDNs.
